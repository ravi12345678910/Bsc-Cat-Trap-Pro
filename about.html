Cat Trap Pro

The ultimate reflex-based cat catching game. Built with pure HTML, CSS, and JavaScript.

No Frameworks Local Storage Dark/Light Mode 10 Levels 3-Star Rating Combo System Combo Multiplier Achievements
🎮

The Game

Cat Trap Pro is an interactive reflex-based game where players test their speed and accuracy by clicking on a moving cat. The game features 10 progressive levels, a 3-star rating system, combo multipliers, and unlockable achievements.

Reflex Game Browser Based Single Player
